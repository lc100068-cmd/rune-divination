# らぴたのルーン占い｜Rapita's Rune Reading

藤色からクリーム、ピンクへ流れるパステルの空に、虹色に発光する渦巻文の壺。
その口から黄金のルーン文字が舞い上がる——
ビジュアルイメージをそのままWebアプリにしたルーン占いです。スマホ／PC どちらでも動きます。

## 占いの流れ

1. **ルーン占いの説明** … ルーンとは何か、読み解きのコツを掲載
2. **引き方をえらぶ** … 一枚引き（今日の指針）／三枚引き（過去・現在・未来）
3. **占いたいことを胸で唱える** … 呼吸のリングを見ながら心の中で3回。言葉にしたい人はテキスト入力も可（任意）
4. **ルーンが舞う** … 壺が光り、ルーン文字が煙とともに宙をくるくると舞い上がる
5. **メッセージ** … ルーンの意味・正位置／逆位置・全体からのメッセージを表示。結果のコピーもできます

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面構造・壺の画像と光の演出のレイヤー |
| `style.css` | パステルの空（青→水色→クリーム→ピンク）、壺のオーラと光の輪、舞い上がるルーンのアニメーション |
| `app.js` | 画面遷移、ルーン抽選、演出制御、結果のコピー |
| `runes.js` | エルダー・フサルク24文字のデータ（意味・正位置／逆位置メッセージ） |
| `pot.webp` | 壺のイラスト（背景透過・640×582） |

## 使い方

5つのファイルを同じフォルダに置いて `index.html` をブラウザで開くだけです。
公開したいときは、そのままサーバーやGitHub Pages、Netlifyなどにアップロードしてください。

## メモ

- ハガル・イサ・ヤラなど、伝統的に逆位置を取らないルーンは常に正位置で出ます
- 三枚引きでは同じルーンが重複しないように引かれます
- `prefers-reduced-motion` をオンにしている端末では演出を控えめにします
- 見出しは明朝体（Shippori Mincho）の金のグラデーション。文字を透明にして背景を
  文字型に切り抜いているため、発光は `text-shadow` ではなく `filter:drop-shadow` で出しています
- 金のグラデーションは行ごとにかけています。見出し全体に1本でかけると、
  上の行が必ずランプの暗い側に入ってしまうためです
- 壺は画像なので、`pot.webp` を差し替えるだけで別の壺にできます（背景透過・幅600px以上を推奨）
- 占い中は壺全体が明るく光ります。浮遊・振動・ルーンの舞い上がりは壺の外側のレイヤーで動いています
- `pot.webp` の切り抜きは、色ではなく「きめ細かさ」で背景と分けています。
  背景は滑らかなグラデーション、壺は模様があるため局所的なばらつきが大きい、という差を使っています
  （色では分離できません。壺の淡い部分のほうが背景より明るい箇所すらあります）
